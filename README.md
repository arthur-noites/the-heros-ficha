# The Heros – Ficha de Personagem

Site estático (HTML, CSS e JS puros) para fichas do RPG The Heros Time.

- Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
- As fichas ficam salvas no navegador (localStorage). Use Exportar/Importar para backup ou para passar a ficha a outra pessoa.
- Publicar no GitHub Pages: suba os arquivos na raiz do repositório e ative Settings > Pages > Deploy from a branch (main, / root).
